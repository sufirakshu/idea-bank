Idea Bank

A public library of ideas documented so they can be explored, developed, built, shared, and carried forward.

What is this?

This is a collection of ideas at different stages of development.

Some ideas may be:

- Raw thoughts
- Early concepts
- Partially developed
- Prototyped
- Built and tested
- Abandoned
- Waiting for someone else to continue them

An idea does not need to become a finished project to be documented here.

The purpose of this repository is to preserve ideas clearly enough that another person can understand them and, if they wish, take them forward.

How the Idea Bank works

Each idea has its own folder and "README.md".

The documentation records:

- Where the idea came from
- The problem it addresses
- What the idea is
- Who it is for
- Its context
- What already exists
- What makes it distinct
- What has already been done
- What remains unfinished
- Possible implementation
- Resources and research
- Open questions
- Risks and limitations
- Its current state

The documentation reflects what was actually discussed or done. Missing information is not invented.

Idea Statuses

Ideas may be marked as:

- RAW IDEA — An initial or lightly documented concept.
- DOCUMENTED — The idea has been documented clearly.
- PROTOTYPED — A prototype or experiment exists.
- PARTIALLY BUILT — Development has begun but is incomplete.
- BUILT — A working version has been created.
- ABANDONED — Development was intentionally stopped.
- ADOPTED — Someone has taken the idea forward.
- ARCHIVED — The idea is no longer active in the main collection.

These statuses describe the state of an idea, not its quality or value.
