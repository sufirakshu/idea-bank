# Archived Ideas

This folder contains ideas that are no longer active in the main Idea Bank.

An archived idea is not necessarily a failed or rejected idea.

It may simply be:

- no longer being worked on
- superseded by another idea
- completed and no longer under development
- intentionally set aside
- no longer relevant to the current Idea Bank

The original documentation and development history should remain intact.
