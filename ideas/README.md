# Idea Bank — Ideas

This folder contains individual ideas documented from Rakshitha Prakash's conversations, notes, experiments, and projects.

Each idea has its own folder and README.

## Idea Structure

Each idea follows this format:

`NNN-[STATUS]-idea-name/README.md`

Example:

`001-[ADOPTED]-wild-womaniya-studio/README.md`

The status at the beginning of the folder name and README title represents the idea's current state.

## Statuses

- RAW — An idea exists but has not yet been properly developed or documented.
- DOCUMENTED — The idea has been captured in the Idea Bank but is not actively being developed.
- WIP — Work is currently in progress.
- PROTOTYPE — A prototype or experimental version exists.
- BUILT — A working version has been created.
- PAUSED — Development has been intentionally paused.
- ADOPTED — The idea has been taken up, used, or incorporated into actual work.
- ARCHIVED — The idea is no longer active but is preserved for reference.

## About the Idea Bank

The Idea Bank is a public record of ideas at different stages of development.

Ideas may be raw, unfinished, abandoned, partially built, researched, prototyped, built, or ready for someone else to develop.

The purpose is documentation and preservation, not evaluation.

Anyone may use, modify, develop, build upon, commercialize, sell, or adapt an idea, subject to the applicable license and attribution requirements documented in the repository.
