# [ADOPTED] IDEA 004 — Multiple Sensory Alternatives Within Each Tool

## Status

ADOPTED

## Date

## Origin

This idea developed during the creation of the Body-First Calm toolkit.

Instead of assuming that one physical or sensory method will work for everyone, the idea was to provide multiple ways of approaching each tool.

## The Problem

A particular sensory or body-based technique may not work for every person or every situation.

A toolkit that offers only one method for each need can therefore limit the user's available choices.

## The Idea

Each tool in a body-based calm toolkit can contain multiple sensory or physical alternatives.

The person can choose the version that feels accessible or appropriate to them rather than being required to use one prescribed method.

## Why This Idea Exists

The idea extends the Body-First Calm approach by making the individual tools flexible rather than fixed.

It also allows different people to interact with the same underlying tool in different ways.

## Who Is It For?

### Primary

People using body-based or sensory tools when they feel overwhelmed.

### Secondary

Not yet defined.

## What Already Exists

The concept of providing multiple sensory alternatives within individual tools was established during toolkit development.

## What Makes This Idea Distinct

The alternatives are contained within the individual tool itself.

The tool therefore represents an underlying purpose or practice, while the user has several possible physical or sensory ways to engage with it.

## What Has Already Been Done

- The concept was identified.
- It was incorporated into the development of the 11-tool toolkit.
- Multiple sensory and physical approaches were explored.

## What Has NOT Been Done

A complete specification of every alternative for every tool has not been documented here.

## Minimum Viable Version

A minimum version would provide:

1. A clearly defined tool.
2. Two or more possible ways of engaging with that tool, where appropriate.
3. Enough explanation for the user to choose an alternative.

## How Someone Could Build It

For each tool:

1. Define the underlying purpose of the tool.
2. Identify different physical or sensory ways of carrying it out.
3. Document the alternatives.
4. Allow the user to choose among them.

The implementation format was not fixed.

## Resources / Research

## Open Questions

- Which alternatives belong to each tool?
- How many alternatives should each tool contain?
- Should alternatives be grouped by sensory preference?
- Should users be able to create their own alternatives?

## Risks / Limitations

The concept does not establish that any particular sensory technique will work for every person.

No clinical efficacy claims are established by this documentation.

## Development History

The idea emerged during the development of the Body-First Calm toolkit as a way to avoid making each tool dependent on a single sensory or physical action.

It became a distinct design principle within the toolkit.
