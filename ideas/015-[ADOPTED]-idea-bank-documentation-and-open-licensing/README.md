## Origin

This idea developed from the desire to preserve ideas that might otherwise remain scattered across conversations, notes, unfinished projects, experiments, and abandoned work.

## The Problem

Ideas can exist at many stages without being formally documented.

An idea may be raw, unfinished, abandoned, partially built, researched, prototyped, or completed. Without documentation, its existence, development history, and context can be difficult for others to discover or understand.

## The Idea

Create a public Idea Bank that documents ideas at every stage of development and makes the documentation openly available for others to use and build upon.

Each idea receives its own documentation containing its origin, context, current state, development history, what has and has not been done, open questions, and relevant implementation information.

The documentation is openly licensed so that other people can use, modify, develop, commercialize, sell, or adapt the ideas with attribution.

## Why This Idea Exists

The Idea Bank is intended to preserve ideas rather than allowing them to disappear simply because they were not completed by their original creator.

The system also allows someone else to discover an unfinished idea and potentially take it forward.

## Who Is It For?

### Primary

People interested in discovering, developing, adapting, or building upon documented ideas.

### Secondary

Creators who want to publicly document and preserve their own ideas.

## Context

The Idea Bank was designed as a public repository containing ideas from conversations, notes, experiments, projects, and other sources.

GitHub was selected as the primary public repository.

## What Already Exists

The Idea Bank repository has been established with:

- A public GitHub repository.
- Individual idea folders.
- README documentation for each idea.
- Status labels.
- Development history.
- Attribution requirements.
- An open licensing structure.

## What Makes This Idea Distinct

The system deliberately documents ideas regardless of their development status.

An unfinished or abandoned idea can therefore remain useful and discoverable instead of being discarded.

## What Has Already Been Done

- The Idea Bank concept was defined.
- A public GitHub repository was created.
- Repository documentation was established.
- A status system was defined.
- Individual ideas were documented.
- A Creative Commons Attribution 4.0 International licensing approach was selected.
- Attribution wording was established.

## What Has NOT Been Done

The complete long-term contribution ecosystem has not been developed.

The process for accepting external contributors and maintaining a large community-generated collection may require further development.

## Minimum Viable Version

A minimum version consists of:

1. A public repository.
2. One folder for ideas.
3. One README per idea.
4. A consistent documentation structure.
5. Visible status information.
6. Attribution.
7. An open license.

## How Someone Could Build It

A person or organization could create a public repository containing:

- A central README.
- Documentation guidelines.
- A license.
- An ideas directory.
- Individual folders for each idea.
- A consistent README template.
- An index of documented ideas.

Ideas could be added regardless of whether they are currently being developed.

## Resources / Research

The repository itself contains the documentation structure, contribution guidance, and licensing information.

The selected license is Creative Commons Attribution 4.0 International (CC BY 4.0).

## Open Questions

- How should external ideas or contributors be handled?
- How should duplicate or overlapping ideas be documented?
- How should ideas be archived?
- How should very large numbers of ideas be indexed?
- How should software code or patentable inventions be handled when they accompany an idea?

## Risks / Limitations

Copyright licensing does not necessarily govern every form of intellectual property.

Software code, trademarks, patents, and other intellectual property may require different legal treatment.

The Idea Bank therefore documents ideas and their associated materials but does not establish ownership or patent rights over an abstract idea merely by documenting it.

## Development History

The Idea Bank developed from the desire to extract and preserve genuine ideas from existing conversations and work.

The concept evolved into a structured public repository where each idea could be documented independently.

An open licensing approach was selected so that people could freely build upon the documented ideas while preserving attribution to the original creator.

## Current State

ADOPTED.

The Idea Bank has been implemented as a public GitHub repository and the first batch of individual ideas is being documented.
